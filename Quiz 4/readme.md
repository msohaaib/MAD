# 💳 Stripe Payment Screen - React Native

A modern, clean, and secure payment screen built with **React Native** and **Stripe**.

## ✨ Features

- Beautiful dark UI design
- Integrated Stripe CardField
- Secure payment handling with Payment Intent
- Loading state with Activity Indicator
- Responsive and premium-looking interface
- Error and success handling with alerts

## 🛠 Technologies Used

- React Native
- @stripe/stripe-react-native
- TypeScript
